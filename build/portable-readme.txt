NameSmith - 파일 이름 일괄 변경기 · 중복 파일 찾기 (무설치 버전)
=================================================================

1. NameSmith.exe 를 더블클릭하면 바로 실행돼요. 설치할 필요가 없어요.
2. 이름을 바꿀 파일이나 폴더를 창으로 끌어다 놓으세요.
3. 오른쪽에서 번호 붙이기 / 찾아 바꾸기 / 날짜 넣기 등을 고르면
   왼쪽 목록에서 바뀔 이름을 바로 미리 볼 수 있어요.
4. 마음에 들면 [이름 바꾸기]를 누르세요.
5. 실수했다면 [되돌리기]를 누르면 원래 이름으로 돌아가요.

중복 파일 찾기
1. 창 위쪽의 [중복 파일 찾기]를 누르세요.
2. 살펴볼 폴더를 끌어다 놓거나 [폴더 추가…]를 누른 뒤 [중복 찾기]를 누르세요.
3. 똑같은 파일과 비슷한 사진이 묶음으로 보여요. 묶음마다 남길 파일
   하나는 체크가 꺼져 있고, 정리할 파일이 체크돼 있어요.
4. [휴지통으로 보내기] 또는 [다른 폴더로 옮기기…]를 누르세요.
   (바로 지우지 않아요. 휴지통에서 되살리거나 [되돌리기]로 돌려놓을 수 있어요.)

"Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
(코드 서명 인증서가 없는 무료 프로그램이라 처음 한 번 나오는 안내예요.)

폴더 오른쪽 클릭 메뉴, 보내기 메뉴, 시작 메뉴 바로 가기가 필요하면
설치 버전(NameSmith-Setup-x.y.z.exe)을 쓰세요.
