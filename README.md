## 다운로드

👉 **[최신 버전 내려받기 (Releases)](https://github.com/game-addicted-man/NameSmith/releases/latest)**

| 파일 | 설명 |
| --- | --- |
| `NameSmith-Setup-x.y.z.exe` | **설치 버전 (추천)** — 시작 메뉴, 바탕 화면 바로 가기, 폴더 오른쪽 클릭 메뉴, 보내기 메뉴까지 한 번에 설정돼요. 관리자 권한이 필요 없어요. |
| `NameSmith-x.y.z-portable.zip` | **무설치 버전** — 압축을 풀고 `NameSmith.exe`를 바로 실행하면 돼요. USB에 넣고 다녀도 돼요. |

> **"Windows의 PC 보호" 창이 뜨면** `추가 정보` → `실행`을 누르세요.
> 코드 서명 인증서(유료)가 없는 무료 프로그램이라 처음 한 번 나오는 안내예요. 소스 코드는 이 저장소에 모두 공개되어 있어요.

## 주요 기능

**이름 바꾸기**

- **번호 붙이기** — `001, 002, 003…` 시작 번호·증가값·자릿수·위치(앞/뒤)·구분 기호를 고르고, 폴더마다 번호를 새로 시작할 수도 있어요.
- **찾아 바꾸기** — `복사본`, `IMG_` 같은 글자를 찾아 바꾸거나 지워요. 대·소문자 구분, 확장자 포함, 정규식(고급)도 돼요.
- **날짜 넣기** — 수정한 날짜, 만든 날짜, **사진·동영상을 찍은 날짜**(JPG, HEIC, PNG, WebP, RAW, MP4, MOV), 오늘 날짜를 원하는 형식으로 넣어요.
- **새 이름 · 글자 추가** — 이름을 통째로 바꾸거나 앞뒤에 글자를 붙여요.
- **기타** — 대·소문자 바꾸기, 확장자 바꾸기/없애기, **맥에서 온 파일의 깨진 한글(ㅅㅏㅈㅣㄴ → 사진) 합치기**.
- **바꾸기 전에 미리 보기** — 바뀔 이름이 바로바로 보여요. 이름이 겹치거나 Windows에서 쓸 수 없는 이름이면 빨간색으로 알려 줘요.
- **수백·수천 개도 한 번에** — 폴더를 통째로 끌어다 놓으면 끝. 하위 폴더까지 넣을 수도 있어요.
- **되돌리기** — 잘못 바꿨다면 버튼 하나로 원래 이름으로 돌아가요.

**중복 파일 찾기** <sup>1.1.0 새 기능</sup>

- **내용이 똑같은 파일** — 이름이나 날짜가 달라도 내용이 같으면 찾아요. 크기 → 파일 앞뒤 일부 → 전체 내용(SHA-256) 순서로 비교해서 빠르고 정확해요. 사진·동영상·음악·문서·압축 파일만 골라서 찾을 수도 있어요.
- **비슷한 사진** — 크기를 줄였거나 다시 저장한 사진, 카톡으로 주고받아 작아진 사진, 밝기를 바꾸거나 글자를 넣은 사진까지 찾아요. 비슷한 정도는 3단계로 고를 수 있어요.
- **남길 파일을 미리 골라 둬요** — 묶음마다 원본으로 보이는 파일 하나는 남기고, `복사본`·`(2)`가 붙은 파일, 백업·다운로드 폴더의 파일, 화질이 낮은 사진을 정리할 쪽으로 체크해 둬요.
- **미리 보기** — 사진은 오른쪽에서 크게 보면서 확인할 수 있어요. 해상도와 찍은 날짜도 보여요.
- **바로 지우지 않아요** — 휴지통으로 보내거나(언제든 되살릴 수 있어요), 다른 폴더로 옮겨요(`되돌리기`로 제자리에).

## 사용법

### 이름 바꾸기

1. **파일 넣기** — 파일이나 폴더를 창으로 **끌어다 놓거나**, `파일 추가…` / `폴더 추가…`를 누르세요.
   탐색기에서 폴더를 오른쪽 클릭 → **NameSmith로 이름 바꾸기**를 골라도 되고, 파일 여러 개를 고른 뒤 오른쪽 클릭 → **보내기 → NameSmith**를 골라도 돼요.
2. **바꿀 방법 고르기** — 오른쪽의 `1. 찾아 바꾸기` ~ `5. 기타` 중 필요한 것에 입력하세요. 입력하면 그 항목이 자동으로 켜지고, 왼쪽 목록의 **새 이름**이 바로 바뀌어 보여요.
3. **순서 정하기** — 번호는 목록 순서대로 붙어요. 열 제목(이름, 수정한 날짜, 크기, 폴더)을 눌러 정렬하거나 `▲ 위로` / `▼ 아래로`로 순서를 바꾸세요. 체크를 끈 파일은 건너뛰어요.
4. **이름 바꾸기** — 미리 보기가 마음에 들면 `이름 바꾸기`를 누르세요.
5. **되돌리기** — 실수했다면 `되돌리기`(Ctrl+Z)를 누르세요. 여러 번 되돌릴 수 있어요.

위쪽의 `이름 바꾸기` / `중복 파일 찾기` 버튼으로 화면을 바꿀 수 있어요. 다음에 켜면 마지막으로 쓴 화면이 열려요.

### 이렇게 쓸 수 있어요

| 하고 싶은 일 | 설정 | 결과 |
| --- | --- | --- |
| 여행 사진을 날짜순으로 정리 | 새 이름 `제주여행` + 날짜(찍은 날짜, 이름 앞) + 번호 | `IMG_1234.JPG` → `2024-05-01_제주여행_001.JPG` |
| "복사본" 지우기 | 찾을 글자 ` - 복사본`, 바꿀 글자 비움 | `보고서 - 복사본.docx` → `보고서.docx` |
| 강의 파일 정렬 문제 해결 | 찾아 바꾸기(정규식) `강의 (\d)\b` → `강의 0$1` | `강의 1.mp4` → `강의 01.mp4` |
| 회사 이름 붙이기 | 앞에 붙이기 `[회사] ` | `견적서.pdf` → `[회사] 견적서.pdf` |
| 확장자 통일 | 기타 → 확장자 `소문자로` | `IMG_0001.JPG` → `IMG_0001.jpg` |
| 스캔 문서 번호 매기기 | 새 이름 `계약서` + 번호(자릿수 2) | `scan0001.pdf` → `계약서_01.pdf` |

### 날짜 형식

`형식` 칸에서 고르거나 직접 입력하세요.

| 글자 | 뜻 | 예 |
| --- | --- | --- |
| `YYYY` / `YY` | 연도 | `2026` / `26` |
| `MM` / `M` | 월 | `05` / `5` |
| `DD` / `D` | 일 | `01` / `1` |
| `HH` / `H` | 시 (24시간) | `13` |
| `mm` | 분 | `45` |
| `ss` | 초 | `30` |
| `ddd` | 요일 | `월` |

예: `YYYY년 M월 D일` → `2026년 5월 1일`, `YYYYMMDD_HHmmss` → `20260501_134530`
(파일 이름에는 `:`를 쓸 수 없어서 시간은 `.`이나 `-`로 나눠 주세요.)

### 안심하고 바꿀 수 있게

- **절대 덮어쓰지 않아요.** 같은 이름의 파일이 이미 있으면 그 파일은 건너뛰어요.
- **이름을 서로 맞바꾸는 경우**(A→B, B→A)나 대·소문자만 바꾸는 경우도 임시 이름을 거쳐 안전하게 처리해요.
- 바꾸는 도중 전원이 꺼져도, 다음에 실행할 때 **남은 작업을 마저 정리**해요.
- 바꾼 내용은 `바꾼 기록 보기`(아래쪽 링크)에 CSV 파일로 남아요. 엑셀로 열어 볼 수 있어요.
- 숨김 파일·시스템 파일(desktop.ini, Thumbs.db 등)은 폴더를 넣을 때 자동으로 빠져요.
- 파일 내용은 건드리지 않아요. 인터넷에 아무것도 보내지 않아요.

## 중복 파일 찾기

<p align="center">
  <img src="assets/screenshot-dupes.png" alt="NameSmith 중복 파일 찾기 화면: 똑같은 파일과 비슷한 사진을 묶음으로 보여 주고, 오른쪽에 사진 미리 보기" width="900">
</p>

1. **화면 열기** — 위쪽의 `중복 파일 찾기`를 누르세요.
   탐색기에서 폴더를 오른쪽 클릭 → **NameSmith로 중복 파일 찾기**를 고르면 그 폴더를 바로 살펴봐요.
2. **찾을 곳 넣기** — 폴더를 창으로 끌어다 놓거나 `폴더 추가…`를 누르세요. 폴더를 여러 개 넣으면 폴더끼리 겹치는 파일도 찾아요.
3. **찾을 것 고르기** — `내용이 똑같은 파일`과 `비슷한 사진` 중 원하는 것을 켜고 `중복 찾기`를 누르세요.
4. **결과 확인하기** — 같은 파일끼리 묶음으로 모아 보여 줘요. 묶음마다 남길 파일(굵은 글씨, `기준 파일 · 남김`)은 체크가 꺼져 있고, 정리할 파일은 체크돼 있어요.
   파일을 고르면 오른쪽에 미리 보기가 나와요. 체크는 직접 바꿔도 되고, 오른쪽 클릭 메뉴의 `이 파일만 남기고 묶음의 나머지는 체크`도 편해요.
5. **정리하기** — `휴지통으로 보내기` 또는 `다른 폴더로 옮기기…`를 누르세요. 다른 폴더로 옮긴 파일은 `되돌리기`(Ctrl+Z)로 원래 자리에 돌려놓을 수 있어요.

### 비슷한 정도

| 고르는 것 | 찾는 사진 |
| --- | --- |
| 거의 똑같은 사진만 | 크기만 다르거나 다시 저장한 사진 |
| 비슷한 사진 (추천) | 위에 더해, 밝기를 바꾸거나 글자를 넣은 사진 |
| 조금 비슷한 사진까지 (연속 촬영 등) | 위에 더해, 살짝 자른 사진, 연이어 찍은 사진 |

결과의 `똑같은 파일`은 내용이 완전히 같은 파일, `모습이 같은 사진`은 파일은 달라도 보기에 똑같은 사진, `97% 비슷`처럼 숫자가 붙은 것은 비슷한 사진이에요.

### 남길 파일 고르는 기준

`남길 파일` 칸에서 바꿀 수 있어요. 바꾸면 모든 묶음의 체크가 다시 정해져요.

| 고르는 것 | 남기는 파일 |
| --- | --- |
| 원본으로 보이는 파일 (추천) | 해상도가 높고 용량이 큰 사진 → 이름에 `복사본`·`(2)`가 없는 파일 → 백업·다운로드·카카오톡 받은 파일 폴더 밖에 있는 파일 → 먼저 만든 파일 순서로 골라요 |
| 화질·용량이 가장 큰 파일 | 해상도가 가장 높은 사진, 같으면 용량이 가장 큰 파일 |
| 가장 오래된 파일 | 수정한 날짜가 가장 이른 파일 |
| 가장 최근 파일 | 수정한 날짜가 가장 늦은 파일 |
| 먼저 추가한 폴더의 파일 | `찾을 곳` 목록에서 위에 있는 폴더의 파일 (예: 정리해 둔 사진 폴더를 먼저, 다운로드 폴더를 나중에 넣기) |

### 안심하고 정리할 수 있게

- **파일을 바로 지우지 않아요.** 휴지통으로 보내거나 다른 폴더로 옮겨요.
- 정리하기 전에 몇 개를 정리하는지 한 번 더 물어봐요. 묶음의 파일이 모두 체크돼 있으면(남는 파일이 없으면) 따로 알려 줘요.
- 숨김·시스템 파일, `Windows`·`Program Files` 같은 시스템 폴더, 휴지통, 아직 내려받지 않은 OneDrive 파일(온라인 전용)은 건드리지 않아요.
- 정리한 내용은 `정리한 기록 보기`(아래쪽 링크)에 CSV 파일로 남아요.
- 사진은 내 PC 안에서만 비교해요. 인터넷에 아무것도 보내지 않아요.

## 자주 묻는 질문

**Windows 11에서 폴더 오른쪽 클릭 메뉴에 안 보여요.**
Windows 11은 오른쪽 클릭 후 `더 많은 옵션 표시`(Shift+F10)를 누르면 나와요.

**아이폰 사진(HEIC)도 비슷한 사진을 찾나요?**
Windows 사진 앱에서 HEIC 사진이 보이면 돼요. 안 보이면 Microsoft Store에서 `HEIF 이미지 확장`과 `HEVC 비디오 확장`을 설치하세요. `내용이 똑같은 파일`은 파일 형식과 상관없이 찾아요.

**동영상이나 음악도 비슷한 것을 찾나요?**
아니요. 동영상·음악·문서는 내용이 똑같은 파일만 찾아요. 카메라 RAW 파일(CR2, NEF, ARW 등)도 JPG와 같이 두는 경우가 많아서 비슷한 사진 비교에서는 빠지고, 똑같은 파일만 찾아요.

**사진이 많으면 처음에 오래 걸려요.**
비슷한 사진을 찾으려면 사진을 한 장씩 열어 봐야 해서 처음에는 시간이 걸려요. 한 번 살펴본 사진은 기억해 두기 때문에 다음부터는 훨씬 빨라요. 도중에 `멈추기`를 눌러도 돼요.

**설정은 어디에 저장되나요?**
`%APPDATA%\NameSmith\settings.json`에 마지막으로 쓴 설정이 저장돼요. 기록은 `%LOCALAPPDATA%\NameSmith\기록`에 있고, 한 번 살펴본 사진 정보도 `%LOCALAPPDATA%\NameSmith`에 저장돼요.

**지우고 싶어요.**
설치 버전은 `설정 → 앱 → 설치된 앱`에서 NameSmith를 제거하세요. 무설치 버전은 폴더를 지우면 끝이에요.

**문제가 생겼어요 / 기능을 제안하고 싶어요.**
[Issues](https://github.com/game-addicted-man/NameSmith/issues)에 남겨 주세요.

## 직접 빌드하기

필요한 것: [Go 1.24 이상](https://go.dev/dl/), (설치 파일을 만들려면) [Inno Setup 6](https://jrsoftware.org/isdl.php)

```powershell
git clone https://github.com/game-addicted-man/NameSmith.git
cd NameSmith
go test ./internal/...
go build -trimpath -ldflags "-s -w -H windowsgui" -o dist\NameSmith.exe .\cmd\NameSmith
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" installer\NameSmith.iss   # dist\NameSmith-Setup-*.exe
```

- 필요한 라이브러리는 `vendor/` 폴더에 들어 있어서 인터넷 없이도 빌드돼요.
- 다른 OS에서도 `GOOS=windows`로 빌드할 수 있어요 (CGO가 필요 없어요).
- `main`에 올릴 때마다 GitHub Actions가 Windows에서 빌드·테스트해요. `VERSION` 파일의 버전을 올려서 push하면 설치 파일과 무설치 zip이 새 Release로 자동 게시돼요.

| 폴더 | 내용 |
| --- | --- |

| `tools/uitest` | 실제 창을 띄워 이름 바꾸기·중복 정리를 해 보는 자동 테스트 (GitHub Actions에서 실행) |
